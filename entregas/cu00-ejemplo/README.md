# CU-00 — Ejemplo

Este fichero no es un README real, sino una nota que explica qué debe
contener el `README.md` de vuestra entrega, según
[`evaluacion/entrega-1.md`](../../evaluacion/entrega-1.md). La forma final
(secciones, orden, redacción) es vuestra: la definís vosotros al escribir el
README de vuestro proyecto, no la copiéis de aquí.

El README debe responder, con vuestras propias palabras y en el orden que
mejor os encaje:

- Qué es el proyecto y qué problema resuelve.
- Por qué habéis escogido este proyecto y qué queréis conseguir al terminarlo.
- Qué entra en el proyecto y qué queda explícitamente fuera.
- Quién forma el equipo, con el rol y el correo de contacto de cada persona.
- Qué contiene cada carpeta y fichero de vuestro repositorio (dónde está el
  README, dónde están las specs, qué hay dentro de cada una).
